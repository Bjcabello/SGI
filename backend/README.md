# Sistema de Gestión de Inventario - Backend

API REST desarrollada con Django y PostgreSQL.

## Instalación

1. Crear entorno virtual: `python -m venv venv`
2. Activar: `venv\Scripts\activate`
3. Instalar dependencias: `pip install -r requirements.txt`
4. Configurar `.env` con credenciales
5. Migrar: `python manage.py migrate`
6. Ejecutar: `python manage.py runserver`
